# CLAUDE.md — Затерянное Королевство

## О проекте
Игра создаётся на Godot 4.6.
Игрок управляет героем на глобальной карте королевства.
Герой перемещается только между путевыми точками (waypoints).

## Важные правила
- Не угадывать координаты объектов.
- Использовать только координаты из `MAP_COORDINATES.md`.
- Не перемещать точки маршрута без необходимости.
- Не удалять существующие сцены без причины.
- Делать небольшие изменения через Pull Request.

## Структура проекта
- `HeroSelect.tscn / HeroSelect.gd` — экран выбора героя (Аэри / Арен)
- `Main.tscn / Main.gd` — карта мира, waypoints, маршруты, разблокировка
- `Hero.gd` — движение и анимация героя
- `GameState.gd` — AutoLoad синглтон (выбранный герой, текущая локация)
- `characters/male_map/frame_1-4.png` — рыцарь (вид сверху для карты)
- `characters/female_map/frame_1-4.png` — воительница (вид сверху для карты)
- Side-view спрайты (`male_side_walk.png`, `female_side_walk.png`) — для боёвки позже

## Текущий MVP
1. Карта мира
2. Выбор героя (Аэри / Арен)
3. Герой на карте с анимацией
4. Перемещение только между соседними точками
5. Разблокировка соседних локаций при посещении
6. Камера следует за героем

## Приоритеты (в порядке)
1. Стабильное перемещение + анимация героя
2. Красивые иконки локаций
3. Туман войны
4. Бои, загадки, квесты

## Не делать пока
- мультиплеер
- магазин / инвентарь
- рекламу
- сложную экономику
