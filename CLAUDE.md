# CLAUDE.md — Lost Kingdom

## Проект
Lost Kingdom — 2D игра на Godot 4.6 с глобальной картой королевства.

Игрок сначала выбирает героя: рыцарь или воительница. Потом выбранный герой ходит по карте только между фиксированными точками маршрута.

## Главное правило
Не угадывать координаты. Все координаты хранятся в `Main.gd` и документируются в `MAP_COORDINATES.md`.

## Текущее MVP
- `HeroSelect.tscn` — экран выбора героя.
- `Main.tscn` — карта мира.
- `Main.gd` — waypoint-точки, маршруты, клики, разблокировка.
- `Hero.gd` — движение героя и анимация.
- `GameState.gd` — выбранный герой и текущая локация.

## Assets
- `maps/world_map.png` — карта.
- `characters/male_map/frame_1.png` ... `frame_4.png` — рыцарь, вид сверху.
- `characters/female_map/frame_1.png` ... `frame_4.png` — воительница, вид сверху.
- Side-view sprites можно использовать позже только для боя/профиля, не для глобальной карты.

## Правила разработки
- Godot 4.6, GDScript.
- Не удалять сцены без необходимости.
- Не добавлять пока магазин, рекламу, мультиплеер и сложный инвентарь.
- Сначала довести карту, выбор героя, движение, анимацию и туман войны.
